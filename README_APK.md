# 四级单词训练 V1.7.0

基于你提供的 V1.6 工程完成稳定性、阅读体验和数据保护优化。原有词库、五页导航、在线发音、离线音频缓存、四种练习、复习计划、收藏和词典资料功能继续保留。

## 这一版的变化

- 修复中文字体默认使用 100 极细字重的问题，随包提供 400 常规、700 粗体；独立 IPA 字体覆盖常用英语音标。中文标题与详情更易读。
- 题目区可滚动，下一题/结束始终在底部；卡片评级和退出按钮也固定在底部。长文本可以扩展高度，新增学习进度条。
- 导入时处理 UTF-8 BOM，并在同一单元内忽略大小写去重。出题再次按单词去重；释义选项保证不同，不足四种释义时改为听音题。
- 综合测试加入听音题。退出练习时取消延时跳题、停止当前音频并使待播放结果失效，防止返回首页后继续出题或发音。
- 卡片数量和顺序遵循设置，卡片学习次数及“认识”次数单独统计，不混入四选一正确率。当前选择的单元也会保存。
- 词典最多两个工作线程、最多十六个待处理查询；手动保存为空的字段也受保护，后续联网结果不会把它覆盖。恢复数据后忽略恢复前的词典响应。
- ZIP 恢复先完整校验文件名、清单、大小及数据结构，拒绝重复项、路径穿越、无效日期、错误类型和超大解压数据。写入失败尝试回滚已经替换的文件。
- 恢复前在手机私有目录保留 before_restore.zip；设置页提供导出入口。原始副本保留旧文件的原始字节，若旧文件本来损坏，副本也可能需要人工修复。
- 继续支持旧版 vocabtrainer-v14 格式；新备份使用 vocabtrainer-v17。恢复前在软件内确认。JSON 保存使用临时文件、刷盘和原子替换。

## 使用完整工程构建

必须整体更新工程，不可只替换 main.py。这版新增 storage.py 与字体文件。

1. 解压工程，把工程目录内所有文件（包括隐藏的 .github 目录）更新到原仓库根目录。
2. 保留原应用包名及原有签名密钥；buildozer.spec 已更新版本号至 1.7.0，沿用原 Android 构建依赖。
3. 在 GitHub Actions 中运行 Build Android APK。构建前会运行语法检查和数据恢复回归测试。
4. 成功后下载 vocab-trainer-apk 构建产物，解压得到 APK。
5. 升级前从旧软件导出学习记录。若提示签名冲突，先核对签名，避免通过卸载丢失旧记录。原工作流不包含签名密钥，本交付也没有代替原密钥生成新的签名。

本交付是完整源码工程，尚未在 GitHub 执行 Android 构建，不包含已编译 APK。没有改成原生鸿蒙工程，仍需要支持安卓应用的运行环境。

## 桌面运行和测试

建议使用 Python 3.11 或 3.12：

```powershell
python -m pip install kivy==2.3.1 certifi
python main.py
python -m unittest discover -s tests -v
```

桌面自动化测试禁用真实网络和发音，使用临时学习数据。桌面环境不提供 Android 系统文件选择器。

## 数据说明

学习统计继续只保存到设备；没有新增遥测、反馈上传或账号服务。原有发音和词典查询会把查询词发送给对应词典服务。备份不包含 MP3 缓存，恢复不会删除缓存；单次 ZIP 与总解压内容上限 25 MiB、单文件上限 8 MiB。

文件级回滚用于处理普通写入异常，无法保证突然断电或进程被强制终止时的跨文件事务；before_restore.zip 用于这种情况下保留恢复前的原始文件。恢复前副本只有最近一次，重要数据请自行导出到手机外。
